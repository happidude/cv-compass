# Milestone and task registry

A folder contains `spec.md` and `verification.md`; start from the
[spec](../templates/spec.md) and [verification](../templates/verification.md)
templates. Maintenance tasks need not be assigned an application milestone number.

| Task | Spec approval evidence | Verification |
| --- | --- | --- |
| Agent workflow maintenance | [Spec](agent-workflow/spec.md): explicit developer task, 2026-10-31 | [Evidence](agent-workflow/verification.md) |

Do not create Active/completed labels from source presence, old logs, branch names
or PR existence. Record a status only with developer confirmation and supporting
spec/PR/commit evidence. Approval and acceptance are separate facts. The
[roadmap](../roadmap.md) currently leaves application statuses unconfirmed.
Keep per-milestone history and verification out of AGENTS.md.
