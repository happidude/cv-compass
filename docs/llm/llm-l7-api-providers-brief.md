# Brief L7 — Provider LLM qua API (OpenAI + Anthropic) để bench so model

Mục tiêu/acceptance: `CVC_LLM_PROVIDER=ollama|openai|anthropic` (mặc định/không đổi env = hành vi cũ). `openai` gọi `POST https://api.openai.com/v1/responses` (model mặc định `gpt-6-luna`, `text.format={type:json_schema,name,schema,strict:true}`, `reasoning.effort` từ `CVC_LLM_REASONING_EFFORT`, mặc định `none`; `max_output_tokens` từ `CVC_LLM_MAX_OUTPUT_TOKENS`). `anthropic` gọi `POST https://api.anthropic.com/v1/messages` (header `x-api-key`, `anthropic-version: 2023-06-01`; model `claude-haiku-5-5`; `output_config.format={type:json_schema,schema}`; `max_tokens` bắt buộc, mặc định 8192; effort thấp/tắt thinking theo https://platform.claude.com/docs/en/build-with-claude/effort). Cả hai trả JSON text cho pipeline như OllamaProvider.
Key: đọc từ biến môi trường `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` (cho phép trong env-file `.env.*` đã gitignore); KHÔNG bao giờ in/log/đưa key vào thông báo lỗi; thiếu key → lỗi `MISSING_API_KEY`.
Schema: gửi schema hiện có; nếu API từ chối từ khóa (vd `minItems/maxItems`, giới hạn anyOf/type-array của Anthropic) thì bỏ các từ khóa đó KHI GỬI, vẫn kiểm tra kết quả bằng schema đầy đủ như cũ. Không đổi prompt/schema/validate.
Lỗi & retry: mã không chứa nội dung (`API_HTTP_<code>`, `API_TIMEOUT`, `API_BAD_RESPONSE`); 429/5xx retry tối đa 3 lần có backoff; không theo redirect; chỉ chấp nhận đúng 2 host trên (https).
Metrics: `prompt_tokens`, `output_tokens` (từ `usage`), `total_ns` đo phía client, `done_reason=length` khi bị cắt (OpenAI `status=incomplete`, Anthropic `stop_reason=max_tokens`). `bench` in tổng token in/out mỗi cấu hình (nếu chưa có). `num_ctx`/`keep_alive`/ctx guard bỏ qua với provider API.
Spec: file này. Chủ dự án 28/11/2026: giai đoạn test chọn model, cho gửi toàn văn CV lên API; Batch API ngoài phạm vi (task sau).
