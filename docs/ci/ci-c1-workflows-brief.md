# Brief C1 — CI cho llm-worker + nâng cấp CI backend/database/frontend/worker

Mục tiêu/acceptance (chủ dự án duyệt 21/11/2026; đây là spec ghi chính xác đường dẫn + ý định theo AGENTS.md):
(1) TẠO `.github/workflows/llm-worker-ci.yml`: chạy khi `pull_request` và `push` vào `main` hoặc `develop` có sửa `llm-worker/**` hoặc chính file workflow, và `workflow_dispatch`. Job trên `ubuntu-24.04`, CPython `3.14.8` (giống worker CI), không cài dependency runtime (llm-worker chỉ stdlib): `PYTHONPATH=src python -m unittest discover -s tests -v`, `ruff check src tests`, `ruff format --check src tests`. Ruff cài từ file khóa hash MỚI `llm-worker/requirements-ci.lock` (chỉ `ruff==<phiên bản>` + `--hash`, cài bằng `pip install --require-hashes --no-deps`); phiên bản ruff = phiên bản đang dùng local (ghi trong PR). Không cần Ollama/backend/CV thật. Upload log khi fail (giữ 7 ngày).
(2) SỬA `frontend-ci.yml`, `persistence-ci.yml`, `worker-ci.yml`:
  a. Thêm nhánh `develop` vào `pull_request`/`push`. Backend (persistence) giữ "mọi PR/push vào main" như hiện tại; với `develop` lọc path `backend/**` + file workflow. Frontend/worker giữ lọc path hiện có. Worker bỏ nhánh `feature/ocr-worker` cũ khỏi `push`.
  b. Thêm `concurrency: { group: <workflow>-<ref>, cancel-in-progress: true }` cho run của PR (không hủy run của push vào main).
  c. Ghim mọi action bên thứ ba theo full commit SHA + comment version (như frontend-ci đang làm); `actions/checkout` đặt `persist-credentials: false`; giữ `permissions: contents: read`.
  d. Backend: thêm upload báo cáo test (`backend/build/reports/**`, `backend/build/test-results/**`) khi fail, 7 ngày.
(3) DATABASE: thêm bước trong `persistence-ci.yml` (chỉ sự kiện pull_request) chạy script MỚI `scripts/ci/check-flyway-immutable.sh`: so `backend/src/main/resources/db/migration/` giữa base và head của PR; FAIL nếu file migration đã có ở base bị sửa/xóa/đổi tên, hoặc file mới có số version ≤ version lớn nhất ở base, hoặc trùng version. Chỉ in tên file + mã lỗi. Có test cho script (bats không có → test bằng bash với repo git tạm trong `scripts/ci/tests/`).
(4) Cập nhật `docs/VERIFICATION.md` mục CI: bảng workflow → trigger → lệnh; thêm llm-worker CI và kiểm Flyway.
Không đổi: lệnh test/build hiện có của từng workflow (không bỏ/skip check, không giảm suite), `runner-hello.yml`, file `claude.yml` chưa track, branch protection/secrets/settings (con người làm).
Spec: file này. Mức/lý do: 3 — sửa CI workflow + thêm công cụ CI (ruff) có khóa hash.
